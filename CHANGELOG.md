# Changelog

## 1.2.0 — Public source preview

This version makes the source available for development and deployment.
The hosted ChatGPT plugin remains private, and its public directory listing
has not been submitted or approved. The files under `publication/` are draft
review materials, not an approved or ready-to-submit plugin release.

### Included

- English setup interface, MCP tool descriptions and public documentation.
- DNS log analysis, official query statistics and profile settings inspection.
- Previewed, authorized changes to individual allowlist and denylist rules and
  supported boolean settings, with current-value checks and result readback.
- User-scoped, encrypted API credentials and deletion of stored connections
  and proposals on disconnect.
- Public bug report and question forms in GitHub Issues.
- MIT licensing for original project code, with retained third-party notices.

### Validation and access

The source includes seventeen implementation checks using synthetic fixtures.
The eight public-directory review cases have not been run in an independent
reviewer installation. A reviewer-accessible demo recording, final service
terms, publisher verification and the remaining submission requirements are
still pending.

Use your own authenticated deployment and NextDNS account. Credentials,
database contents and personal DNS traffic are not included in this source.

GitHub's source archives are sufficient for distributing this web application;
no npm or container package is needed for this preview.
