# Security policy

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/erikleblansch/nextdns-assistant/security/advisories/new)
for security issues affecting NextDNS Assistant. Do not report exploitation
details or sensitive information in public issues.

Include the affected commit or version, expected and observed behavior, and a
minimal reproduction with fictional data. Do not include API keys, profile IDs,
IP addresses, personal DNS logs, database exports or environment secrets.
Only test systems and accounts you are authorized to test.

If private reporting is unavailable, open a minimal public issue asking for a
private reporting channel without including sensitive details. No fixed response
time is guaranteed.
